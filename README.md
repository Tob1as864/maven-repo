# maven-repo

Stores all builds for my open source projects.

This repository is a plain **Maven repository**: it holds the released `.jar`
files together with their `.pom` descriptors and checksums, in the directory
layout Maven expects. Because GitHub serves raw files over
`raw.githubusercontent.com`, it can be used directly as a repository in any
Maven or Gradle build — **no GitHub account, token or `settings.xml` entry is
required**.

Its contents are generated by the release workflows of the individual project
repositories. Please do not commit here by hand.

## Using it

Add the repository once, then declare the libraries you need as ordinary
dependencies.

### Maven

```xml
<repositories>
  <repository>
    <id>tob1as864</id>
    <url>https://raw.githubusercontent.com/Tob1as864/maven-repo/main</url>
  </repository>
</repositories>

<dependencies>
  <dependency>
    <groupId>de.uni_stuttgart.ils</groupId>
    <artifactId>reqif4j</artifactId>
    <version>1.1.0</version>
  </dependency>
</dependencies>
```

### Gradle

```kotlin
repositories {
    maven { url = uri("https://raw.githubusercontent.com/Tob1as864/maven-repo/main") }
}

dependencies {
    implementation("de.uni_stuttgart.ils:reqif4j:1.1.0")
}
```

## Available libraries

| Library | Coordinates | Source |
| --- | --- | --- |
| reqif4j | `de.uni_stuttgart.ils:reqif4j` | [ReqIF-Parser-Java](https://github.com/Tob1as864/ReqIF-Parser-Java) |

A Java parser and writer for ReqIF (Requirements Interchange Format) documents.

To see which versions exist, browse the directory tree of this repository:
each library lives under its groupId path, for example
[`de/uni_stuttgart/ils/reqif4j`](de/uni_stuttgart/ils/reqif4j).

Sources and javadoc jars are published next to every version, so IDEs can show
the API documentation automatically.

## Notes

- **Caching.** `raw.githubusercontent.com` is served through a CDN, so a freshly
  published version can take a few minutes to become resolvable.
- **Development builds.** Versions ending in `-SNAPSHOT` are unfinished work
  towards the next release and may change at any time. Maven picks them up
  automatically; to keep them out of a build, disable them for this repository:
  ```xml
  <snapshots><enabled>false</enabled></snapshots>
  ```
- **Licensing.** Each artifact keeps the license of the project it was built
  from; see the respective source repository.
